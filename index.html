Your first search in a few lines

Typed clients for TypeScript and Python, and a plain HTTP API for everything else. The same query works in all three.

  • Hybrid ranking is on by default
  • Filter on any metadata field
  • One namespace per customer
  • Answers stream as they are written
See what the API covers 
import { Sounder } from "sounder";

const sounder = new Sounder({
  apiKey: process.env.SOUNDER_KEY,
});

const { hits } = await sounder.search({
  index: "help-center",
  query: "refund after 30 days",
  filter: { lang: "en" },
  topK: 3,
});

console.log(hits);

Questions

Not answered here? Write to us and an engineer will reply.

What counts as a vector?

One embedded passage with its text and metadata. A 2,000 word document usually becomes 8 to 12 vectors.

Which embedding models can I use?

Bring your own vectors, or let Sounder embed for you with one of its hosted open models. You can switch models later and re-embed in the background.

Do I still need a keyword search engine?

No. Every query blends vector and keyword ranking, and you can weight one over the other per query.

How fresh is the index?

A write is searchable in about a second. Synced sources check for changes every minute, or right away when they send a webhook.

Where is my data stored?

In the region you pick, encrypted at rest and in transit. Enterprise plans can run in a private region inside your own cloud account.

What happens if I go over my estimate?

Nothing stops. You get an email at 80% and 100% of a budget you set, and you can put a hard cap on any key.
